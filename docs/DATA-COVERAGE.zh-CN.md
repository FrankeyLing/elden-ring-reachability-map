**语言**: [English](../README.md) · [中文](./DATA-COVERAGE.zh-CN.md)

- **938 节点**：604 个赐福（官方赐福目录 418 条全量补齐，192 条新入图并接入区域网络）、入口、Boss、升降梯、传送点、关键地标。
- **1,601 条有向边**：在线交叉核对边 + 18 条本地声明桥接边（跨区域缺口补齐）+ 4 条人工核对连接（灰烬王城出边）+ 384 条官方赐福区域内部桥接边。

- 区域解析权威链路：地图文件中的地名标识 → 官方文本地名（含 DLC：塔之镇贝瑞特/神兽舞台/望影露台），tile 主区域索引，以及一跳邻居投票推断的无名网格图。

## 覆盖声明

- 正式图覆盖：938 节点（604 赐福）、1,601 条已证实有向边、177 个状态条件、1 个弱连通分量。
- 数据包：`surface-main-world` / `underground` / `royal-capital` / `ashen-capital` / `shadow-realm` / `farum-azula` / `haligtree` / `stormveil` / `raya-lucaria` / `volcano-manor` / `caria-manor` / `legacy-other` / `bridge`。
- 坐标仅用于自制抽象底图布局，非游戏原始 XYZ；cost/risk 为相对单位，非实测分钟。
- 本地考据图（29,144 节点 / 7,976 条候选边）为证据仓库，不在玩家关键路径上；开发检查入口为 `/research.html`。
- 独立抽象拓扑候选层：1,351 个地图节点、1,347 个原生地图层节点、1,347 条地图到层关系、2,092 条地图级候选边、18 条交互传送证据；其中包含 1,588 条地图声明、149 条精确地图端点对、15 条精确脚本传送边和 340 条脚本传送证据（79 条使用边自身地图标识，261 条由端点节点的本地地图标识补全）。其中 2,079 条边已经具有本地身份支持的抽象连接，13 条仍是未解析候选；18 条交互传送均有抽象目标身份，但运行时条件仍独立保留。原始地图中有 50 张明确记录为缺少原生层证据，另有 4 个外部声明地图占位节点。该层全部保持 `routeable=false`，抽象连接也不等于正式玩家路线，不会污染正式路线图。
- 候选层接口为 `/api/abstract-topology-candidates`、`/api/abstract-topology-candidates/map?map_id=...` 和 `/api/abstract-topology-candidates/path?from_map_id=...&to_map_id=...`；路径接口只返回抽象身份连接证据轨迹，不宣称玩家路线。玩家实体拓扑详情中的 `abstractTopology` 只展示相关候选证据，`routeNodeIds` 仍只代表正式路线节点。
- 独立原生抽象拓扑包覆盖 1,347 张地图的覆盖记录，其中 997 张有原生分区文件、350 张缺失；已收录 9,480 个分区节点、5,884 条精确连接声明和 11,646 条分区到地图部件身份映射。接口为 `/api/abstract-native-topology` 和 `/api/abstract-native-topology/map?map_id=...`，全部保持 `routeable=false`。
- 独立获取桥接包包含 71,563 条终点记录：66,893 条来自获取关系，4,670 条来自覆盖缺口。其中 32,231 条是精确抽象地图层锚点，32,507 条是精确抽象地图锚点，37 条是候选地图锚点，1,999 条仅有外部地图范围，4,789 条仍未绑定或未解析。接口为 `/api/acquisition-topology-bridge`、`/api/acquisition-topology-bridge/map?map_id=...` 和 `/api/acquisition-topology-bridge/relation?relation_id=...`。该桥接包只是可搜索的证据投影，全部保持 `routeable=false`，不会进入正式路线图。
- 其中 3,713 个本地拾取终点通过 `ItemLotParam_map` 批次编号与地图身份精确绑定到语义拾取节点。该锚点与正式路线资格独立，不会生成导航边。
- 另有 348 个敌人、伪敌人、商人、任务角色或 Boss 奖励终点，通过地图身份、部件名、实例编号、实体编号和地图层编号五项身份精确绑定到本地抽象部件节点。31,883 个身份完整但暂时没有对应部件节点，195 个身份字段不完整；这些记录仍可搜索且相互隔离。
- 独立地，32,231 个敌人、伪敌人、商人、任务角色和 Boss 奖励终点已经使用上述五项身份字段，与已复制的本地出生实例快照精确连接。该连接只证明数据源中的实例身份，不证明抽象移动节点、步行可达性或路线边；其中 348 个抽象部件匹配是这个身份层的更严格子集。
- 候选层不依赖连续碰撞、导航网格或物理模拟；原生地图声明、方向、状态条件和端点阻断原因均随证据保留，未解析项不能被当作可达路线。
- 独立抽象拓扑轨迹包包含 1,351 个地图节点、1,347 个地图层节点和 2,097 条有向身份支持连接。接口 `/api/abstract-topology-route?from_map_id=...&to_map_id=...` 返回地图/楼层拓扑轨迹及条件警告；它与正式玩家路线图独立，玩家路线字段仍为 `routeable=false`。
- `/api/catalog/player-entity-topology?id=...` 另外提供 `abstractRouteEvidence`，按该实体获取端点绑定的地图投影有限的关联边证据。它包含匹配地图/地图层、地图—地图层包含关系、相邻地图编号、未匹配的请求地图编号和关联边计数；边明细最多 2,000 条。该投影是可独立失效的可选证据层，并且始终区分 `abstractRouteable` 与 `playerRouteable=false`、`routeable=false`，因此证据包损坏不会使实体搜索或获取数据失效。
- `/api/catalog/player-entity-abstract-route?id=...&from_map_id=...` 从指定起始地图执行一次抽象图搜索，返回精确获取目标地图的可达性、终点引用、路径证据，以及独立的候选/外部/未解析/未绑定计数；使用 `target_map_id=...` 可缩小查询范围。这是抽象地图轨迹，不是连续步行路线，也不是正式玩家路线。
- `abstract-origin-bindings.json` 收录 419 条 Compass 赐福身份，并通过地图编号加赐福实体编号与本地赐福位置快照精确连接：39 条精确人工正式起点绑定、376 条名称/地图候选、2 条歧义候选和 2 条未绑定正式身份。`/api/catalog/player-entity-abstract-route` 只允许这 39 条精确记录使用 `from_node_id=...`，其它起点状态返回明确阻断原因并继续作为可搜索证据保留。
- 规范武器实体保留本地参数中的装备族信息，现有 562 个武器实体中包括：近战 399、弓 19、弩 9、弩炮 3、法杖 20、圣印记 12、盾牌 85、火把 8、徒手武器 2、调香瓶武器 5。装备族只是查询属性和别名，不会复制实体或伪造获取关系。
- 桥接边与区域内部桥接边带有 `local_declared` / `catalog_grace` 标签和证据说明，非已验证步行路线。

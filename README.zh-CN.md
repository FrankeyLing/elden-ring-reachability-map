# 艾尔登法环可达性地图

**语言**: [English](README.md) · [中文](README.zh-CN.md)

《艾尔登法环》多位面拓扑路线规划器：以固定在线资料为主数据源、以本地游戏数据副本做完整性校验的有向条件图，按当前世界状态返回关键节点序列、通行方式、单向性、层级变化与条件说明。

## 快速开始

```bash
python server.py --port 8105
# 浏览器打开 http://127.0.0.1:8105/
```

页面首屏只加载数据包清单、13 个数据包与路线配置，不加载任何本地研究索引。默认示例路线为「黄金树大教堂 → 古兰桑克斯的雷电」。

## 使用方法

### 1. 规划一条路线

- **起点 / 终点**：在左侧搜索框输入中文或英文名称（支持官方中文别名，如"玛利喀斯"、"史东薇尔正门"、"黄金树大教堂"），从下拉结果中选择；也可点击「⇅ 交换起终点」对调。
- **世界状态**：勾选当前进度条件（Boss 已击败、钥匙、王城状态等）。「全部勾选 / 全部清除」可快速切换。
- **通行方式**：默认"物理拓扑 / 禁止快速旅行"；切换"正常流程 / 允许快速旅行"后，勾选"允许地图快速旅行"即可在已发现赐福间传送。
- **路线偏好**：平衡 / 最快 / 低风险。
- 点击「规划可达路线」后，右侧显示路线卡片：每一步包含通行方式、方向（单向跳落不会反向）、层级变化、条件要求、数据包版本与证据等级。

### 2. 阅读地图

- **默认视图为区域聚合**：先显示 122 个区域节点（官方中文名、节点数与赐福数），区域间以虚线聚合边相连；**点击区域下钻**到内部拓扑，点「← 返回全局」回到聚合视图。
- **图层切换**：地表 / 地下 / 遗迹建筑层；路线经过的节点在任何图层下始终可见。
- **缩放与平移**：滚轮以鼠标位置为中心缩放；左键按住拖动平移；右上角按钮可缩放/重置。移动端支持双指捏合缩放与单指拖动。
- **缩放分级**：远视图只显示区域名；放大后依次显示节点名与层级信息。
- **数据包状态**：右侧"数据包状态与覆盖声明"面板列出 13 个数据包加载状态、隔离记录与连通分量；局部数据失败只影响对应区域。

### 3. 研究控制台（开发检查入口）

`http://127.0.0.1:8105/research.html` 提供本地研究数据与证据链的检查视图，不参与玩家路线关键路径。
